# 🚀 ATS Resume Maker — Free Builder Platform

A **100% free, privacy-first** web application to create job-winning, ATS-optimized resumes in minutes. No signup, no credit card, no data collection — everything runs locally on your device.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-basicresumebuild.netlify.app-blue?style=for-the-badge)](https://basicresumebuild.netlify.app/)

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Live ATS Coach** | Real-time ATS match score + missing keyword suggestions with 1-click `+ Add to Skills` |
| **12+ Templates** | Standard ATS, Software Eng, Data Analyst, Creative Photo, Sales, Marketing, Executive, Compact 1-Page, and more |
| **Photo Upload** | Candidate headshot support for creative & modern templates |
| **1-Page Auto-Fit** | Live page spilling detector with 1-click spacing density control |
| **10+ Fonts** | Inter, Outfit, Poppins, Plus Jakarta Sans, Lora, JetBrains Mono, Fira Code, and more |
| **Industry Presets** | 1-click demo data for Software Engineer, Data Analyst, Marketing Manager, Sales Director |
| **Export Options** | PDF download, JSON backup, plain text export |
| **100% Private** | Zero server calls — all data stays in your browser's local storage |

## 🚀 Quick Start

```bash
git clone https://github.com/Shashiverm/resume-Maker.git
cd resume-Maker
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

**Other commands:**
```bash
npm run lint          # ESLint check
npx tsc --noEmit      # TypeScript check
npm run build         # Production build
```
