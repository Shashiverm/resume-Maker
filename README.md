# 🚀 ATS Resume Maker & Free Builder Platform

Inspired by world-class platforms like **Resume.io**, **Zety**, **Novaresume**, **BetterCV**, and **Resume-Now** — **ATS Resume Maker** is a 100% free, privacy-first web application designed to create job-winning, ATS-optimized resumes in minutes.

---

## 🌟 Key Features

- ⚡ **Real-Time Live ATS Optimization Coach**: Calculates your ATS match score live as you type, providing missing keyword suggestions with 1-click **`+ Add to Skills`** buttons.
- 📄 **12+ Specialized Industry Templates**:
  - **Standard ATS Classic**: 100% machine-readable single-column layout for corporate applicant tracking systems (Greenhouse, Lever, Workday, Taleo).
  - **Software Engineering & Tech**: Syntax accents, technical stack chips, GitHub repository highlights.
  - **Data Science & Analytics**: Quantitative metrics grid, SQL/Python skill matrix.
  - **Creative Photo & Headshot**: Sleek candidate profile picture avatar frame and contemporary typography.
  - **Sales & Revenue Leadership**: ACV callouts and quota achievement emphasis.
  - **Digital Marketing Lead**: Dark emerald header banner and campaign metrics.
  - **Executive & Corporate**: Board-level serif formatting and executive highlight box.
  - **Compact 1-Page Fit**: Dense grid layout for 10+ years experience on a single sheet.
- 🖼️ **Candidate Profile Photo / Headshot Upload**: Upload profile pictures for creative and modern template designs.
- 📏 **Live 1-Page Spilling Detector & Auto-Fit**: Real-time height detector (`⚡ 1-Page Perfect Fit` vs `📄 Spilling onto 2 Pages`) with 1-click **Auto-Fit 1 Page** spacing density control.
- 🔤 **Expanded Typography Library**:
  - **Sans-Serif**: Inter, Roboto, Outfit, Poppins, Plus Jakarta Sans
  - **Serif**: Merriweather, Playfair Display, Lora
  - **Monospace**: JetBrains Mono, Fira Code
- 🔒 **100% Free & Privacy-First**: 0 signup required, 0 credit cards, 100% private local storage saving, and instant unlimited PDF downloads.
- 💼 **One-Click Industry Presets**: Pre-populated realistic demo data for Software Engineers, Data Analysts, Marketing Managers, and Sales Directors.
- 💾 **JSON & Plain Text Backup**: Export/Import `.json` backup files or plain text (`.txt`) for easy updates.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with Glassmorphism & Custom Glow Utilities
- **Icons**: [Lucide React](https://lucide.dev/)
- **PDF Generation**: `html2pdf.js`

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation & Local Run

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Shashiverm/resume-Maker.git
   cd resume-Maker
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Lint & Type Check**
   ```bash
   npm run lint
   npx tsc --noEmit
   ```

5. **Production Build**
   ```bash
   npm run build
   ```
